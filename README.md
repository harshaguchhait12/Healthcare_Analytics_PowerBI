🏥 Healthcare Analytics Dashboard | Power BI

 📌 Project Overview

The Healthcare Analytics Dashboard is an interactive data visualization project developed using Microsoft Power BI. It analyzes 1,200 patient records across 23 fields to generate meaningful insights into patient demographics, clinical characteristics, hospital performance, treatment costs, and healthcare utilization.

The dashboard helps users monitor key healthcare metrics, identify trends, compare different categories, and support data-driven decision-making through interactive filters and visualizations.

 🎯 Project Objectives

- Analyze patient demographics and healthcare information.
- Monitor important healthcare KPIs.
- Understand patient distribution across hospitals and departments.
- Analyze diagnoses, admission types, and patient outcomes.
- Explore treatment costs and length of hospital stays.
- Identify patterns and areas requiring further investigation.
- Build an interactive dashboard for healthcare data analysis.

 Dataset Fields

The dataset contains the following important attributes:

- **Patient Information:** Patient_ID, Patient_Name, Age, Gender
- **Hospital Information:** Hospital, Department, Doctor
- **Clinical Information:** Diagnosis, Admission_Type, Bed_Type
- **Admission Details:** Admission_Date, Discharge_Date, Admission_Year, Admission_Month
- **Healthcare Metrics:** Length_of_Stay, Treatment_Cost
- **Insurance Details:** Insurance_Provider
- **Patient Performance:** Patient_Status, Outcome, Readmission, Patient_Satisfaction

 📈 Dashboard Features & Visualizations

The dashboard provides an interactive overview of healthcare operations through the following visualizations:

1. **Patients by Department** – Displays patient distribution across different hospital departments.
2. **Patients by Gender** – Analyzes the gender distribution of patients.
3. **Patients by Stay Group** – Compares patients based on their length of hospital stay.
4. **Patients by Diagnosis** – Shows the distribution of different medical diagnoses.
5. **Patients by Hospital** – Compares patient distribution across hospitals.
6. **Treatment Cost Analysis** – Provides insights into healthcare treatment expenses.
7. **Patient Outcome Analysis** – Displays the distribution of patient outcomes.

Interactive Filters (Slicers)

Users can dynamically filter dashboard information using:

- Hospital
- Admission Year
- Department

🚀 How to Run the Project

1. Clone or download this repository.
2. Open the `Dashboard` folder.
3. Download and install Microsoft Power BI Desktop if required.
4. Open `health care.pbix`.
5. If necessary, update the Excel dataset file path in Power Query.
6. Click **Refresh** to load the latest dataset.
7. Explore the dashboard using interactive slicers and visualizations.
